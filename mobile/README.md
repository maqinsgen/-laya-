# 知灯 Notewake Mobile

新增：消息评分与解释、有用/没用/撤销反馈、“完成与反馈记录”视图，反馈通过原有加密文档同步到桌面。完整操作与当前构建验证状态见 [信息助手使用指南](../使用指南-信息助手.md)。

Android / iOS 伴侣端，同桌面端共享端到端加密的 WebDAV 待办文档。移动端不尝试读取微信私有数据库；微信与邮件采集、AI 提取在桌面端完成，手机只同步最小化后的待办结果。

## 本地运行

```bash
npm install
npm run build
npm run sync
```

Android 需要 JDK 21 与 Android SDK：

```bash
cd android
./gradlew assembleDebug
```

调试 APK 输出在 `android/app/build/outputs/apk/debug/app-debug.apk`。

iOS 需要安装完整 Xcode，然后运行：

```bash
npm run ios
```

## 首次连接

1. 在桌面端待办页面配置 WebDAV，保存自动生成的恢复密钥。
2. 在手机端填写相同的 WebDAV 地址、用户名、密码、远端路径和恢复密钥。
3. 点击“连接并同步”。只有成功读取并解密桌面已上传的文档，才保存手机配置；密码、路径或恢复密钥错误会留在当前页面并提示原因。
4. 原生 App 的凭据进入系统安全存储，本地待办缓存先加密。浏览器预览使用浏览器存储，仅供开发调试，请不要输入真实凭据。
5. 可在底部“连接设置”修改参数，网络失败可重试；离线完成待办与反馈会保留，联网后再次同步。

恢复密钥无法从远端密文中找回。遗失后，已有设备仍可使用，但新设备无法解密旧数据。

## 原生能力

- Android / iOS：本地截止提醒、系统交互式新增日历事件、分享今日壁纸。
- Android：用户开启开关后，每天首次打开或同步时可直接设置系统桌面壁纸。
- iOS：Apple 没有向普通第三方 App 开放静默更换壁纸 API，因此应用生成图片并打开系统分享面板，由用户保存或交给快捷指令处理。

## 发布检查

- Android：配置 release signing、真机验证通知精确闹钟授权、日历权限与壁纸行为。
- iOS：在完整 Xcode 环境下验证签名、`PrivacyInfo.xcprivacy`、日历/通知权限和 TestFlight 归档。
- 两端：使用两台设备分别编辑、完成、删除同一个待办，验证 ETag 重试、冲突合并和墓碑删除。
